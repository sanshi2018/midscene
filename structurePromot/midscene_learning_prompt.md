# 必须覆盖的核心学习要点

下面这份清单是我希望你**完整覆盖**的研究点。你可以自由决定把它们分到哪些 MD 里，但**一个都不能漏**。

## A. Prompt 模板设计模块

- A1. **System Prompt 的角色定义与能力边界**：找出 Midscene 给 VLM 设的 Persona、约束、禁止行为
- A2. **多模态上下文的拼装**：自然语言指令 + base64 截图如何融合进 User Prompt
- A3. **输出格式强制约束**：Function Calling / JSON Schema 如何强制模型只输出 `tap` / `input` / `scroll` 等结构化动作 + reasoning
- A4. **三大 API 的 Prompt 变体对比**：`aiAction`（执行）、`aiAssert`（断言）、`aiQuery`（提取）的 Prompt 差异，尤其 `aiQuery` 是否还保留 DOM 上下文

## B. 核心执行器流（Action Executor / Planner）

- B1. **Screenshot → Analyze → Act 循环**：单步 / 多步规划机制
- B2. **页面就绪等待**：执行动作前后的 `sleep` / `waitForNetworkIdle` / 视觉稳定性判定
- B3. **统一跨端驱动抽象**：Web（Playwright/Puppeteer）+ Android（ADB）+ iOS（WebDriverAgent）共用一套 Adapter 接口的设计
- B4. **失败重试 & 错误恢复**：模型规划错误（如点击不可见元素）时的捕获 → 重截图 / 滚动 / 报错决策
- B5. **缓存与回放（🧊 Frozen Context）**：UI 状态 + Prompt 的 Hash 策略，回归测试如何跳过 LLM 推理

## C. 图像预处理与坐标映射模块

- C1. **图像 Resize / 压缩**：长截图、宽截图的裁剪与质量压缩策略，如何在不丢关键 UI 特征下省 Token
- C2. **相对坐标 → 绝对坐标**：UI-TARS 等模型输出 `[0,1000]` 千分位坐标的逆向换算
- C3. **DPR（Device Pixel Ratio）对齐**：Retina 高分屏 `1:2`/`1:3` 物理像素与 CSS 逻辑像素的映射
- C4. **滚动偏移补偿**：目标元素在首屏外 / 全页面拼图截图场景，如何计算 scrollY 把目标滚入视口再点

## D. 工程挑战专题（深层博弈）

- D1. **确定性 vs 幻觉对抗**：自愈能力（self-healing）、UI 微调时如何区分"正常迭代"与"功能错误"；相似元素歧义消解
- D2. **性能与成本**：VLM 推理延迟（秒级）在 CI/CD 的致命性；缓存机制、小/大模型调度切换、图像切片（Image Patching）/ ROI 提取
- D3. **反馈闭环 & 视觉断言**：`aiAssert` 是用 Visual Diff 还是让模型用自然语言描述当前状态再匹配；多步操作中第 N 步失败的回溯定位
- D4. **长序列规划（Long-horizon Planning）**：跨页面跳转的操作记忆（Memory/History）；视频进度条、无限滚动、拖拽验证码等动态 / 时间维度 UI 的处理
- D5. **跨平台一致性**：系统级弹窗、状态栏、底部虚拟键的标准化屏蔽

## E. 高级 / 前沿话题（放最后一个 MD 综合讨论）

- E1. **数据隐私与 PII 脱敏**：发往云端 VLM 前的本地脱敏方案设计 / 框架现状
- E2. **连续型微操与复杂手势**：Drag-and-Drop、Hover 等待子菜单、Slider、多指触控；如何用 Playwright 模拟带阻尼的人类拖拽轨迹（应对滑动验证码）
- E3. **模型漂移（Model Drift）**：底层 VLM 微调导致坐标分布偏移；Midscene 是否有 Evaluation / Benchmark 基准集
- E4. **纯视觉 vs 混合模态（SOM, Set-of-Mark）**：极端复杂 UI 下是否偷偷混入 DOM 辅助；架构上是否预留了 SOM 标记法
- E5. **异步状态管理 & "死锁"**：Loading 转 10 秒时如何判定"页面加载完毕"；纯视觉 vs DOM `networkidle` vs Visual Diff 的平衡
